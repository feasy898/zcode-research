Works in two places

A step in a workflow. A tool on an agent.

Installing once covers both.

In a workflow

  1. 01Install the pack into your HubSpot portal.
  2. 02Add a BuilderPack action to any workflow and map its inputs.
  3. 03Use its output tokens in any later step.

On an agent

  1. 01Create or open an agent in Agent Builder.
  2. 02Add BuilderPack tools on the Actions tab.
  3. 03Run the agent from the Agent Inbox or from chat.

Ready to try them?

Install once with HubSpot OAuth. No API keys, no per-action setup. You’ll need a HubSpot Professional or Enterprise plan; Agent Builder isn’t available on Free or Starter portals.
